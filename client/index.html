연결 확인 중

로그인 후 현재 진행 상태를 확인합니다.

이 관리자 탭에서 한 번 소리를 준비하세요. 무작위 또는 상위 5개·전체 낭독 중에만 음악이 재생됩니다. 스피커 연결은 현장에서 확인하세요.

현재—

현재 회차의 공개 동의·상영 가능 사연만 출력합니다. 무작위 모드만 설정한 간격마다 한 편씩 반복합니다. 직접 낭독은 ‘네’ 사연을 접수순으로 보여 주며 아래에서 순서를 조정할 수 있습니다. 낭독은 다음/이전/선택으로 진행하며 자동으로 넘기지 않습니다. 회차를 바꾸면 안전을 위해 일시정지합니다.

현재 회차 간격 확인 중

현재 회차 설정에만 저장됩니다. 적용 시 현재 사연을 즉시 넘기지 않고 그 시점부터 새 간격을 셉니다. 일시정지는 해제되지 않습니다.

이 선택은 새 사연의 접수 회차에만 적용됩니다. 기존 미분류 글은 검수 탭에서 배정하세요.

빔프로젝터 화면 열기 ↗. 영사 화면은 로그인 없이 서버 진행을 표시합니다. 시작·일시정지·재개·긴급 정지는 이 관리 화면에서만 조작합니다. 관리 창을 닫아도 인증 유효기간 동안 계속됩니다. 로그아웃·인증 만료·서버 재시작 후에는 관리자 재로그인·시작이 필요합니다. 일시정지는 진행 위치를 보존하고, 긴급 정지는 배경만 표시합니다.

직접 낭독 순서

현재 회차의 낭독 희망자 전체 순서입니다. 위/아래로 옮긴 뒤 저장하세요. 상위 5명이 선정되며, 대기·불가 또는 동의하지 않은 글은 포함하지 않습니다.

    관리자 낭독 원고 · 현재 회차

    원고를 입력·저장한 뒤 ‘저장 원고 선택’을 누르고 관리자 낭독 원고 모드로 전환하세요. 저장이나 모드 전환만으로 원고를 자동 선택하지 않습니다. 선택한 원고만 아래에서 위로 이동하며 원문 줄바꿈을 유지합니다. 빈 원고·선택 해제는 표시하지 않습니다.

    선택 없음

    엔딩 고정 문구 · 현재 회차

    고정 문구와 해당 회차의 크레딧 동의 별명이 함께 아래에서 위로 이동합니다. 원문 줄바꿈을 유지합니다. 미리보기만으로 저장하지 않습니다.

    03 · 추억 관리
    원문은 그대로, 표시는 따로
    원문·작성 시각·응답은 별도 보존합니다. 대기/상영 가능/상영 불가를 선택하세요. 불가 글은 상영·엔딩에서 제외됩니다. 숨김도 DB와 결과 정리에 포함하며 자동 삭제하지 않습니다. 영구 삭제는 모든 응답·수정 이력을 지우며 복구할 수 없습니다. 새 동의 글은 공개·상영 기간 제한이 없고, 기존 글은 작성 후 7일 공개 조건을 유지합니다. 검수 상태를 바꾸거나 문구를 편집해도 동의 범위는 바뀌지 않으며 만료된 기존 글은 재공개되지 않습니다. 동의 철회·공개 중단·삭제 요청(__DELETION_CONTACT__)은 확인 후 숨김·영구 삭제로 처리하세요. 삭제 재전송 방지를 위해 내용 없는 요청 번호만 남깁니다.
    결과 CSV 내려받기 · 전체 상태 포함
    로그인 필수 · UTF-8 BOM CSV · Excel/Google Sheets에서 직접 열기. Google Sheets 자동 동기화가 아닙니다. 개인정보가 포함되므로 승인되지 않은 외부 공유·복제는 하지 마세요.
    이 상태의 추억이 없습니다.
